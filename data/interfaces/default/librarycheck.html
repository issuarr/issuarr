Tools › Library check

Opens every comic in your series folders and reads it through, to find files that are damaged, aren't comics at all, have no pages, or wrap another .cbz or .cbr instead of pages. It also counts issue files with no ComicInfo.xml, which readers like Kavita show as a separate series, and can tag them from the details Issuarr already has. Files are remembered, so the next run only opens ones that changed. Nothing happens to a file until you choose; files you remove go to the trash for ${trash_days} days.
